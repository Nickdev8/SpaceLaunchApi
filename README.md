# Rocket Launches

This website provides information about upcoming rocket launches. It fetches data from the RocketLaunch API and displays the next five launches, including details such as the launch provider, vehicle, time, and location.

## Features

- Displays a list of upcoming rocket launches
- Provides detailed information about each launch
- Allows users to enable notifications for upcoming launches

## How to Access

You can access the website at [iotservice.nl/rockets](http://iotservice.nl/rockets).

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP

## Setup

1. Clone the repository.
2. Ensure you have a web server with PHP support.
3. Place the files in the web server's root directory.
4. Access the website through your browser.

## API

The website uses the RocketLaunch API to fetch data about upcoming launches.
